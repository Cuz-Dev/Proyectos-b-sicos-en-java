Hola, Gracias por visitar mi repositorio
de Proyecto Java básicos,

Para poder ejecutar el Programa se necesito
el Driver JDBC de java para bases de datos;

El sistema tienda de inventario funciona para 
pc con el editor de código vsc, además de que se 
debe cambiar el archivo launch.json, debido 
a qué el vsc no habre la base de datos y el archivo Main
al mismo tiempo, o si no puedes ejecutar el comando 

java -cp ".;sqlite-jdbc.jar" Main

en la terminal,
los tres archivos deben estar en la misma carpeta 
es decir Main.java, tienda.db, y el driver yo uso la versión 
sqlite-jdbc-3.53.4.0
